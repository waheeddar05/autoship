Task Workflows

Configure automated quality gates for incoming ClickUp tasks. When a task triggers automation, an AI evaluates its description for completeness before execution begins.

🎯 Quality Score Threshold
Score Threshold (0–100)
Tasks scoring below this are rejected; tasks scoring at or above are approved. AI evaluates: title clarity, problem statement, acceptance criteria, technical details, edge cases, scope, testing approach, and dependencies.
70
🚫
Reject Flow
When quality score is BELOW threshold
What happens when a task fails quality check
1. AI posts a structured rejection comment on the ClickUp task listing specific quality issues
2. Task is re-assigned to the creator (via task.creator.id)
3. Task status is changed (see below)
4. Optional tag is added to the task
Reject Status
ClickUp status to set when task is rejected
Needs Revision Tag
Optional tag to add (leave empty to skip)
✅
Approve Flow
When quality score is AT or ABOVE threshold
What happens when a task passes quality check
1. Task status changed to Development
2. AI generates a structured coding plan (summary, files, steps, edge cases, testing)
3. Coding plan is posted as a comment on the ClickUp task
4. Task tagged "Awaiting Plan Approval"
5. System watches for approval keywords in comments
6. On approval → AutoShip pipeline executes, creates branch + PR
Approve Status
ClickUp status when task passes quality check
PR Raised Status
ClickUp status after PR is created
Approval Keywords
Comma-separated keywords that trigger execution (matched in ClickUp comments)
Require Repo Field
When enabled, tasks without a Repo custom field will be rejected with a comment instead of generating a speculative plan
🧠 Debate vs Direct Planning
Controls when multi-model debate is used. Simple and medium tasks are planned directly (faster). Complex tasks can go through multi-model debate for more thorough review.
Minimum Complexity for Debate
Tasks at or above this complexity level will use multi-model debate (if enabled). Tasks below this are planned and executed directly.
